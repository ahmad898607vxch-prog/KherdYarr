# خردیار (KherdYar)

نسخه شروع پروژه وب‌اپ تلگرام خردیار برای پایه هشتم.

## اجرا

1. Node.js نسخه 18 یا بالاتر نصب باشد.
2. در پوشه پروژه اجرا کنید: `npm install`
3. سپس: `npm start`
4. برنامه روی پورت 3000 اجرا می‌شود.

## تنظیم معلم هوشمند

متغیرهای محیطی را در بخش Environment سرویس میزبانی تنظیم کنید:
- `OPENAI_API_KEY`: کلید API محرمانه؛ فقط در سرور نگهداری شود.
- `OPENAI_MODEL`: اختیاری؛ پیش‌فرض `gpt-4.1-mini`.
- `BOT_TOKEN`: توکن ربات تلگرام، فقط در سرور.
- `REQUIRE_TELEGRAM_AUTH`: تا زمان راه‌اندازی و آزمون اعتبارسنجی تلگرام، false بماند.

این نسخه نمونه اولیه است و هنوز پنل مدیریت، پرداخت، بانک اطلاعاتی و دسترسی پولی را پیاده‌سازی نکرده است.
